# Dateien offline verfügbar machen

Sie können Dateien offline verfügbar machen, sodass sie auch ohne Internetverbindung zugänglich sind.

- Tippen Sie auf die drei Punkte (⋯) neben der Datei

<img src={require("../img/files-and-folders/make-available-offline/three-dots.png").default} alt="Offline verfügbar machen" width="184" height="400" loading="lazy" decoding="async"/>

- Wählen Sie "Offline verfügbar machen" aus

Die Datei wird heruntergeladen und lokal auf Ihrem Gerät gespeichert.

<img src={require("../img/files-and-folders/make-available-offline/make-available-offline.png").default} alt="Offline verfügbar machen" width="184" height="400" loading="lazy" decoding="async"/>

- Offlinedateien sind mit einem Wolkensymbol mit Häkchen gekennzeichnet.

<img src={require("../img/files-and-folders/make-available-offline/marked-offline.png").default} alt="Offline verfügbar machen" width="184" height="400" loading="lazy" decoding="async"/>

## Offline-Verfügbarkeit entfernen

So geben Sie Speicherplatz frei:

- Tippen Sie erneut auf die drei Punkte (⋯) einer Offline-Datei.
- Wählen Sie "Offline-Zugriff entfernen".

Mit diesen Funktionen sind Sie immer vorbereitet – auch wenn Sie offline sind!
