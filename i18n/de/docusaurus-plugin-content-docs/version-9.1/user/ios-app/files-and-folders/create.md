# Dateien und Ordner erstellen

Mit der OpenCloud iOS-App können Sie direkt auf Ihrem iPhone oder iPad neue Ordner und Dokumente erstellen, Fotos oder Videos aufnehmen und Papierdokumente scannen.

- Tippen Sie oben rechts auf die Schaltfläche "+".

<img src={require("../img/files-and-folders/create/create-new.png").default} alt="Neu erstellen" width="184" height="400" loading="lazy" decoding="async"/>

Wählen Sie aus dem Menü aus, was Sie erstellen möchten:

## Erstellen Sie einen Ordner

– Tippen Sie auf "Ordner erstellen"
– Geben Sie einen Namen für Ihren Ordner ein
– Tippen Sie auf "Done"

<img src={require("../img/files-and-folders/create/create-folder.png").default} alt="Ordner erstellen" width="184" height="400" loading="lazy" decoding="async"/>

## Erstellen Sie ein Dokument (erfordert Collabora)

Wenn Collabora Online in Ihrer OpenCloud-Instanz aktiviert ist:

– Tippen Sie auf "Neues Dokument"
– Wählen Sie den Dokumenttyp (Text, Tabelle, Präsentation)
– Geben Sie einen Dateinamen ein und bestätigen Sie.

<img src={require("../img/files-and-folders/create/choose-file-type.png").default} alt="Wählen Sie den Dateityp" width="184" height="400" loading="lazy" decoding="async"/>

Das Dokument wird zur Bearbeitung in einer integrierten Webansicht mit Collabora geöffnet.

<img src={require("../img/files-and-folders/create/open-collabora.png").default} alt="In Collabora öffnen" width="184" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/create/edit-collabora.png").default} alt="In Collabora bearbeiten" width="184" height="400" loading="lazy" decoding="async"/>

## Machen Sie ein Foto oder Video

- Wählen Sie "Foto oder Video aufnehmen" aus dem Menü

<img src={require("../img/files-and-folders/create/select-take-photo.png").default} alt="wählen Sie Foto oder Video aufnehmen aus" width="184" height="400" loading="lazy" decoding="async"/>

– Die Kamera Ihres Geräts wird geöffnet.
– Nehmen Sie ein Foto oder Video auf.

<img src={require("../img/files-and-folders/create/take-photo.png").default} alt="Machen Sie ein Foto" width="185" height="400" loading="lazy" decoding="async"/>

- Die Medien werden direkt in Ihrem OpenCloud-Konto gespeichert

<img src={require("../img/files-and-folders/create/photo-saved.png").default} alt="Foto gespeichert" width="184" height="400" loading="lazy" decoding="async"/>

## Dokument scannen

Scannen Sie Papierdokumente mit Ihrem iOS-Gerät:

- Wählen Sie "Dokument scannen"
- Richten Sie die Kamera auf Ihr Dokument.
- OpenCloud erkennt die Ränder automatisch und scannt das Dokument.

Sie können dann:

– Den Scan zuschneiden oder drehen
– Den Farbmodus wechseln (Farbe, Graustufen, Schwarzweiß)
– Ein Dateiformat wählen (PDF, JPEG, PNG)
– Als einseitige oder mehrseitige Datei speichern

Das gescannte Dokument wird in Ihrem OpenCloud-Konto gespeichert.
