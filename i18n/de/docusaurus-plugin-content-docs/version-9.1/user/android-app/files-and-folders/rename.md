# Dateien und Ordner umbenennen

So benennen Sie eine Datei oder einen Ordner in der OpenCloud Android-App um:

- Tippen Sie auf die „drei Punkte (…)“ neben dem Element, das Sie umbenennen möchten

<img src={require("../img/files-and-folders/rename-android/three-dots.png").default} alt="Drei-Punkte-Menü" width="180" height="400" loading="lazy" decoding="async"/>

- Wählen Sie „Umbenennen“ aus dem Menü

<img src={require("../img/files-and-folders/rename-android/select-rename.png").default} alt="Umbenennen wählen" width="180" height="400" loading="lazy" decoding="async"/>

- Geben Sie den neuen Namen für die Datei oder den Ordner ein

<img src={require("../img/files-and-folders/rename-android/enter-rename.png").default} alt="Neuen Namen eingeben" width="180" height="400" loading="lazy" decoding="async"/>

- Tippen Sie auf „OK“, um die Änderungen zu übernehmen

<img src={require("../img/files-and-folders/rename-android/tap-ok.png").default} alt="OK tippen" width="180" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/rename-android/new-name-applied.png").default} alt="Neuer Name übernommen" width="180" height="400" loading="lazy" decoding="async"/>

Der neue Name wird sofort gespeichert.
