# Dateien und Ordner verschieben

Sie können Dateien und Ordner an einen anderen Speicherort in OpenCloud verschieben.

1. Wählen Sie die zu verschiebende Datei beziehungsweise den zu verschiebenden Ordner aus.

   <img src={require("./img/move/mark-folder.png").default} alt="Zum Verschieben ausgewählter Ordner" width="1920" height="1080" loading="lazy" decoding="async"/>

2. Wählen Sie „Verschieben nach“ auf eine der folgenden Arten:
   - Öffnen Sie das Kontextmenü, indem Sie mit der rechten Maustaste auf das ausgewählte Element klicken oder dessen Drei-Punkte-Menü öffnen. Wählen Sie anschließend „Verschieben nach“.

     <img src={require("./img/move/right-click-move-to-option.png").default} alt="Option Verschieben nach im Kontextmenü" width="400" height="703" loading="lazy" decoding="async"/>

   - Wählen Sie „Verschieben nach“ in der Aktionsleiste.

     <img src={require("./img/move/actionbar-move-to-option.png").default} alt="Option Verschieben nach in der Aktionsleiste" width="1920" height="1080" loading="lazy" decoding="async"/>

3. Wählen Sie im Dialog den Zielordner und anschließend „Hierher verschieben“.

   <img src={require("./img/move/move-dialog.png").default} alt="Dialog zur Auswahl des Zielordners" width="1920" height="1080" loading="lazy" decoding="async"/>

4. Das verschobene Element wird im Zielordner angezeigt und befindet sich nicht mehr am ursprünglichen Speicherort.

   <img src={require("./img/move/moved-file.png").default} alt="Verschobenes Element im Zielordner" width="1920" height="1080" loading="lazy" decoding="async"/>
