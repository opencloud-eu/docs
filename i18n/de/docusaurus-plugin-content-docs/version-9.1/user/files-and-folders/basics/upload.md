# Dateien und Ordner hochladen

Sie können Dateien und Ordner von Ihrem Gerät in OpenCloud hochladen.

- Öffnen Sie das Menü „+ Neu“ in der linken Seitenleiste.

  <img src={require("./img/upload/upload-button.png").default} alt="Hochladen-Schaltfläche" width="1920" height="520" loading="lazy" decoding="async"/>

- Wählen Sie aus, ob Sie Dateien oder Ordner hochladen möchten.

  <img src={require("./img/upload/upload-options.png").default} alt="Datei oder Ordner auswählen" width="400" height="84" style={{ display: "block", marginTop: "1rem", marginBottom: "1rem" }} loading="lazy" decoding="async"/>

- Dateien oder Ordner auswählen:
  - Wählen Sie im sich öffnenden Fenster die gewünschten Dateien oder Ordner aus.
  - Mehrere Dateien oder Ordner können gleichzeitig ausgewählt werden.
- Upload bestätigen:
  - Klicken Sie auf „Öffnen“, um den Upload zu starten.

    <img src={require("./img/upload/upload-window.png").default} alt="Upload bestätigen" width="500" height="341" loading="lazy" decoding="async"/>

  - Nach Abschluss des Uploads erscheint eine Meldung in der unteren rechten Ecke.

- Alternativ:
  - Ziehen Sie die Dateien oder Ordner direkt aus Ihrem Explorer-Fenster in den Browser, um sie hochzuladen.
