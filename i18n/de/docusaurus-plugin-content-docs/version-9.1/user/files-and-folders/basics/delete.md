# Dateien und Ordner löschen

Sie können Dateien und Ordner löschen, die Sie nicht mehr benötigen. Gelöschte Elemente werden zunächst in den Bereich „Gelöschte Dateien“ verschoben und können von dort wiederhergestellt werden.

- Wählen Sie die Dateien oder Ordner aus, die Sie löschen möchten.

  <img src={require("./img/delete/mark-folder.png").default} alt="Dateien oder Ordner auswählen" width="1920" height="1080" loading="lazy" decoding="async"/>

- Öffnen Sie das Kontextmenü und wählen Sie „Löschen“.

  <img src={require("./img/delete/delete-options.png").default} alt="Löschen auswählen" width="1920" height="1080" loading="lazy" decoding="async"/>

:::info
Alternativ können Sie auch in der Aktionsleiste auf „Löschen“ klicken.
:::

- Die Dateien oder Ordner werden in den Bereich „Gelöschte Dateien“ verschoben. Sie können bei Bedarf von dort wiederhergestellt werden.

  <img src={require("./img/delete/folder-in-deleted-files.png").default} alt="Dateien und Ordner in den gelöschten Dateien" width="1920" height="1080" loading="lazy" decoding="async"/>

Wie Sie gelöschte Elemente zurückholen, erfahren Sie unter [Dateien und Ordner wiederherstellen](./restore.md).
