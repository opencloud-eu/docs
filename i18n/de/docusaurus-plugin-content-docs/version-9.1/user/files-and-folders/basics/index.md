# Grundlagen

Die Grundlagen für die Arbeit mit Dateien und Ordnern in OpenCloud.  
In diesem Abschnitt erfahren Sie, wie Sie neue Inhalte erstellen, Dateien in OpenCloud hochladen und wieder auf Ihr Gerät herunterladen sowie Elemente löschen und aus dem Papierkorb wiederherstellen.

## In diesem Abschnitt

- [Dateien und Ordner erstellen, umbenennen und verschieben](./create-rename-move.md)  
  Erstellen Sie neue Dateien und Ordner, benennen Sie sie um und verschieben Sie sie an einen anderen Ort.

- [Inhalte hochladen, herunterladen und entpacken](./upload-download-unzip.md)  
  Laden Sie Dateien und Ordner von Ihrem Gerät hoch, laden Sie sie wieder herunter oder entpacken Sie ZIP-Archive direkt in OpenCloud.

- [Elemente löschen und wiederherstellen](./delete-restore.md)  
  Verschieben Sie Dateien und Ordner in den Papierkorb und stellen Sie sie wieder her, wenn Sie sie erneut benötigen.
