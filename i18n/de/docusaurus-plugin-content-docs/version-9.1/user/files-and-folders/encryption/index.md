# Verschlüsselung

Schützen Sie besonders sensible Inhalte mit Ende-zu-Ende-Verschlüsselung.  
Dateien und Dateinamen in einem verschlüsselten Ordner werden bereits im Browser verschlüsselt, bevor sie hochgeladen werden. Lesen kann sie nur, wer Zugriff auf den Ordner hat und das Passwort kennt. In diesem Abschnitt erfahren Sie, wie Sie verschlüsselte Ordner erstellen und nutzen und wie Sie mit rclone darauf zugreifen.

## In diesem Abschnitt

- [Ende-zu-Ende-verschlüsselte Ordner](./e2ee-folders.md)  
  Erstellen Sie passwortgeschützte Ordner, deren Inhalt vor dem Hochladen verschlüsselt wird.

- [Mit rclone auf verschlüsselte Ordner zugreifen](./e2ee-folders-rclone.md)  
  Binden Sie einen verschlüsselten Ordner unter Linux, macOS oder Windows mit rclone ein.
