# Einen Space in OpenCloud anpassen

Sie können einen Space entweder in der Space-Übersicht oder direkt im Space selbst anpassen.

## Beschreibung bearbeiten

Öffnen Sie das Drei-Punkte-Menü, wählen Sie „Anpassen“ und anschließend „Beschreibung bearbeiten“. Geben Sie Ihre Beschreibung in den Texteditor ein. Speichern und schließen Sie ihn anschließend.

<img src={require("./img/customize/description-edit.png").default} alt="Beschreibung bearbeiten" width="1920"/>
<img src={require("./img/customize/description-change.png").default} alt="Beschreibung ändern" width="1920"/>

Die Beschreibung kann auch direkt im Space bearbeitet werden, indem Sie auf den Stift daneben klicken.

## Untertitel bearbeiten

Öffnen Sie das Drei-Punkte-Menü, wählen Sie „Anpassen“ und anschließend „Untertitel bearbeiten“. Geben Sie den gewünschten Untertitel ein und speichern Sie ihn.

<img src={require("./img/customize/subtitle-edit.png").default} alt="Untertitel bearbeiten" width="1920"/>
<img src={require("./img/customize/subtitle-change.png").default} alt="Untertitel ändern" width="1920"/>

## Bild festlegen

Öffnen Sie das Drei-Punkte-Menü, wählen Sie „Anpassen“ und anschließend „Bild festlegen“. Wählen Sie das gewünschte Bild für Ihren Space aus, passen Sie den Bildausschnitt an und bestätigen Sie die Auswahl.

<img src={require("./img/customize/image-edit.png").default} alt="Space-Bild auswählen" width="1920"/>
<img src={require("./img/customize/image-size.png").default} alt="Space-Bild zuschneiden" width="1920"/>
<img src={require("./img/customize/image-set.png").default} alt="Space-Bild" width="1920"/>

## Symbol festlegen

Öffnen Sie das Drei-Punkte-Menü, wählen Sie „Anpassen“ und anschließend „Symbol festlegen“. Wählen Sie das gewünschte Symbol für Ihren Space aus.

<img src={require("./img/customize/icon-set.png").default} alt="Symbol festlegen" width="1920"/>
<img src={require("./img/customize/icon-select.png").default} alt="Symbol auswählen" width="500"/>
<img src={require("./img/customize/icon-spaceimage.png").default} alt="Symbol als Space-Bild" width="1920"/>

Jetzt wissen Sie, wie Sie einen Space anpassen können.
