# Dateien und Ordner verschieben oder kopieren

So verschieben Sie eine Datei oder einen Ordner in der OpenCloud Android-App:

- Tippen Sie auf die „drei Punkte (…)“ neben der Datei oder dem Ordner, die bzw. den Sie verschieben möchten

<img src={require("../img/files-and-folders/move-android/three-dots-move.png").default} alt="Drei-Punkte-Menü auswählen" width="180" height="400" loading="lazy" decoding="async"/>

- Wählen Sie „Verschieben“ oder „Kopieren“ aus dem Menü

<img src={require("../img/files-and-folders/move-android/select-move-or-copy.png").default} alt="Verschieben oder Kopieren wählen" width="180" height="400" loading="lazy" decoding="async"/>

Navigieren Sie zum Zielordner  
Tippen Sie auf „Hierher verschieben“ oder „Hierher kopieren“

<img src={require("../img/files-and-folders/move-android/select-paste.png").default} alt="Einfügen auswählen" width="180" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/move-android/file-moved.png").default} alt="Datei wurde verschoben" width="180" height="400" loading="lazy" decoding="async"/>

Die Datei oder der Ordner wird nun am neuen Speicherort angezeigt.
