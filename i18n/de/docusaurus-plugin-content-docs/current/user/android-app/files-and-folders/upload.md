# Dateien hochladen

Mit der OpenCloud Android-App können Sie Dateien von Ihrem Gerät hochladen oder Fotos und Videos direkt mit der Kamera aufnehmen und hochladen.

## Gewünschten Ordner öffnen

Navigieren Sie zu dem Ordner, in dem Sie eine Datei hochladen möchten.

## Tippen Sie auf das „+“-Symbol unten rechts

und wählen Sie „Hochladen“

<img src={require("../img/files-and-folders/upload-android/upload-plus-button.png").default} alt="Plus-Schaltfläche" width="180" height="400" loading="lazy" decoding="async"/>

## Upload-Option wählen

Im Menü können Sie wählen:

- „Hochladen“ – eine Datei aus dem Gerätespeicher hochladen
- „Bild von Kamera“ – ein Foto oder Video mit der Kamera des Smartphones oder Tablets aufnehmen und hochladen

<img src={require("../img/files-and-folders/upload-android/upload-options.png").default} alt="Upload-Optionen" width="180" height="400" loading="lazy" decoding="async"/>

## Auswahl bestätigen

Wählen Sie die Datei oder das Medium aus, das Sie hochladen möchten. Der Upload startet automatisch.
