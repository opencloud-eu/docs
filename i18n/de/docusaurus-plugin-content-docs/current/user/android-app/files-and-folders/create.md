# Dateien und Ordner erstellen

Mit der OpenCloud Android-App können Sie neue Ordner und Dokumente direkt auf Ihrem Smartphone oder Tablet erstellen.

Tippen Sie auf das „+“-Symbol unten rechts.

<img src={require("../img/files-and-folders/create-android/create-new.png").default} alt="Neu erstellen" width="180" height="400" loading="lazy" decoding="async"/>

Wählen Sie im Menü aus, was Sie erstellen möchten:

## Ordner erstellen

- Tippen Sie auf „Neuer Ordner“
- Geben Sie einen Namen für Ihren Ordner ein
- Tippen Sie auf „OK“

<img src={require("../img/files-and-folders/create-android/create-folder.png").default} alt="Ordner erstellen" width="180" height="400" loading="lazy" decoding="async"/>

## Dokument erstellen (erfordert Collabora)

Wenn Collabora Online in Ihrer OpenCloud-Instanz aktiviert ist:

- Tippen Sie auf „Neues Dokument“
- Wählen Sie den Dokumenttyp (Text, Tabelle, Präsentation)
- Geben Sie einen Dateinamen ein und bestätigen Sie

<img src={require("../img/files-and-folders/create-android/choose-file-type.png").default} alt="Dateityp wählen" width="180" height="400" loading="lazy" decoding="async"/>

Das Dokument wird in einem integrierten Browserfenster mit **Collabora** zur Bearbeitung geöffnet.

<img src={require("../img/files-and-folders/create-android/open-collabora.png").default} alt="Collabora öffnen" width="180" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/create-android/edit-collabora.png").default} alt="Collabora bearbeiten" width="180" height="400" loading="lazy" decoding="async"/>
