# Shortcut in der OpenCloud iOS-App

Hier zeigen wir dir, wie du Shortcuts in der iOS-App erstellst.

## „+“-Symbol

- Tippe auf das „+“-Symbol

  <img src={require("./img/shortcuts/plus-button.png").default} alt="Plus symbol" width="184" height="400" loading="lazy" decoding="async"/>

## Drop-down-Menü

- Es öffnet sich ein Drop-down-Menü

  <img src={require("./img/shortcuts/plus-menu.png").default} alt="Drop-down menu" width="184" height="400" loading="lazy" decoding="async"/>

## Shortcut erstellen

- Wähle „Shortcut erstellen“ aus

  <img src={require("./img/shortcuts/create-shortcut.png").default} alt="Select create shortcut" width="184" height="400" loading="lazy" decoding="async"/>

## Shortcut-Optionen

- Es öffnet sich ein Menü mit Optionen für Shortcuts

  <img src={require("./img/shortcuts/shortcut-menu.png").default} alt="Shortcut menu" width="184" height="400" loading="lazy" decoding="async"/>

## URL

- Um einen Shortcut zu einer Website zu erstellen, gib unter „URL“ die Adresse der Website ein

  <img src={require("./img/shortcuts/url.png").default} alt="URL" width="184" height="400" loading="lazy" decoding="async"/>

## Dateien und Ordner auswählen

- Um einen Shortcut zu einer Datei oder einem Ordner in OpenCloud zu erstellen, tippe auf die Option „Datei oder Ordner auswählen“

  <img src={require("./img/shortcuts/pick-file-or-folder.png").default} alt="Select file or folder option" width="184" height="400" loading="lazy" decoding="async"/>
  <img src={require("./img/shortcuts/choose-file-or-folder.png").default} alt="Select file or folder" width="184" height="400" loading="lazy" decoding="async"/>
  <img src={require("./img/shortcuts/select-button.png").default} alt="Select" width="184" height="400" loading="lazy" decoding="async"/>

## Shortcut-Name

- Gib hier einen Namen für den Shortcut ein, unter dem er angezeigt werden soll

  <img src={require("./img/shortcuts/shortcut-name.png").default} alt="Name of the shortcut" width="184" height="400" loading="lazy" decoding="async"/>

## Erstellen-Button

- Tippe auf „Shortcut erstellen“, um den Shortcut zu erstellen

  <img src={require("./img/shortcuts/create-shortcut-button.png").default} alt="Create shortcut" width="184" height="400" loading="lazy" decoding="async"/>

## Erstellter Shortcut

- Dein erstellter Shortcut wird nun angezeigt und kann verwendet werden

  <img src={require("./img/shortcuts/created-shortcut.png").default} alt="Shortcut" width="184" height="400" loading="lazy" decoding="async"/>
