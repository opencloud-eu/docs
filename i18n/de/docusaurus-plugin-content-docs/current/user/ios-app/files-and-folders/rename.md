# Dateien und Ordner umbenennen

So benennen Sie eine Datei oder einen Ordner in der OpenCloud iOS-App um:

- Tippen Sie auf die drei Punkte (⋯) neben dem Element, das Sie umbenennen möchten.

<img src={require("../img/files-and-folders/rename/three-dots.png").default} alt="Klicken Sie auf das Drei-Punkte-Menü" width="184" height="400" loading="lazy" decoding="async"/>

- Wählen Sie "Umbenennen" aus dem Menü

<img src={require("../img/files-and-folders/rename/select-rename.png").default} alt="Wählen Sie umbenennen" width="184" height="400" loading="lazy" decoding="async"/>

- Geben Sie den neuen Namen für die Datei oder den Ordner ein

<img src={require("../img/files-and-folders/rename/enter-rename.png").default} alt="Geben Sie den neuen Namen ein" width="184" height="400" loading="lazy" decoding="async"/>

- Tippen Sie auf "Done", um die Änderungen zu übernehmen

<img src={require("../img/files-and-folders/rename/tap-done.png").default} alt="Tippen Sie auf fertig" width="184" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/rename/new-name-applied.png").default} alt="Neuer angewendeter Name" width="184" height="400" loading="lazy" decoding="async"/>

Der neue Name wird sofort gespeichert.
