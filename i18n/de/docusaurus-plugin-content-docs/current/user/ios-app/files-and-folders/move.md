# Dateien und Ordner verschieben oder kopieren

So verschieben Sie eine Datei oder einen Ordner in der OpenCloud iOS-App:

- Tippen Sie auf die drei Punkte (⋯) neben der Datei oder dem Ordner, die/den Sie verschieben möchten.

<img src={require("../img/files-and-folders/move/three-dots-move.png").default} alt="Wählen Sie das Drei-Punkte-Menü" width="184" height="400" loading="lazy" decoding="async"/>

- Wählen Sie "Ausschneiden" oder "Kopieren" aus dem Menü

<img src={require("../img/files-and-folders/move/select-cut-or-copy.png").default} alt="Wählen Sie Ausschneiden oder Kopieren" width="184" height="400" loading="lazy" decoding="async"/>

- Navigieren Sie zum Zielordner.
- Tippen Sie auf die drei Punkte (⋯) im Zielordner und wählen Sie Einfügen.

<img src={require("../img/files-and-folders/move/select-paste.png").default} alt="Wählen Sie einfügen" width="184" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/move/file-moved.png").default} alt="Datei ist verschoben" width="184" height="400" loading="lazy" decoding="async"/>

Die Datei oder der Ordner wird jetzt am neuen Speicherort angezeigt.
