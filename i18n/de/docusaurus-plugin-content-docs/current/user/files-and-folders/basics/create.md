# Dateien und Ordner erstellen

In OpenCloud können Sie ganz einfach neue Ordner sowie Text-, Tabellen- und Präsentationsdateien in der Weboberfläche erstellen.

- Öffnen Sie das Menü „+ Neu“ in der linken Seitenleiste.
  <img src={require("./img/create/new-button.png").default} alt="Neue Schaltfläche" width="1920" height="900" loading="lazy" decoding="async"/>
- Wählen Sie entweder „Ordner“ oder den gewünschten Dateityp aus.
  <img src={require("./img/create/create-options.png").default} alt="Dateityp oder Ordner auswählen" width="400" height="558" loading="lazy" decoding="async"/>
- Geben Sie im angezeigten Fenster einen Namen für die Datei oder den Ordner ein.
- Klicken Sie auf „Erstellen“.

  <img src={require("./img/create/create-button.png").default} alt="Auf Erstellen klicken" width="400" height="260" loading="lazy" decoding="async"/>

Fertig. Die Datei oder der Ordner wurde erstellt. Wenn es sich um eine Datei handelt, wird sie automatisch im Bearbeitungsmodus geöffnet.
