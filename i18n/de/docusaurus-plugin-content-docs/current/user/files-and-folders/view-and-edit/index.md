# Ansehen und Bearbeiten

Öffnen und bearbeiten Sie Ihre Inhalte direkt im Browser, ohne sie vorher herunterzuladen.  
Dieser Abschnitt behandelt die Vorschau von Fotos und Videos, den integrierten Markdown-Editor und README-Dateien, die den Inhalt eines Ordners beschreiben.

## In diesem Abschnitt

- [Fotos und Videos](./photos-and-videos.md)  
  Sehen Sie sich Fotos in der Vorschau an, blättern Sie durch eine Fotoansicht und spielen Sie Videos in der Weboberfläche ab.

- [Markdown-Dateien bearbeiten](./markdown-editor.md)  
  Bearbeiten Sie `README.md` und andere Markdown-Dateien direkt in OpenCloud mit Formatierungsvorschlägen.

- [README-Dateien in Ordnern](./readme-files.md)  
  Legen Sie eine `README.md` in einem Ordner ab, damit OpenCloud sie oberhalb der Dateiliste anzeigt.
