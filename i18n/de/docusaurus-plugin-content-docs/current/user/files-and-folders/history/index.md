# Verlauf und Aktivitäten

Verstehen Sie, wie sich Ihre Dateien im Laufe der Zeit verändert haben.  
In diesem Abschnitt erfahren Sie, wie Sie frühere Versionen einer Datei öffnen und wiederherstellen und wie Sie sehen, welche Aktionen an einer Datei oder einem Ordner ausgeführt wurden und von wem.

## In diesem Abschnitt

- [Dateiversionen](./versions.md)  
  Sehen Sie sich frühere Versionen einer Datei an und stellen Sie bei Bedarf einen älteren Stand wieder her.

- [Aktivitäten](./activity.md)  
  Sehen Sie, welche Aktionen an einer Datei oder einem Ordner ausgeführt wurden und wer die Änderungen vorgenommen hat.
