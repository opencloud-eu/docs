# Verknüpfung

Mit OpenCloud können Sie Verknüpfung zu Websites oder Dateien erstellen

## Verknüpfung erstellen

- Klicken Sie auf "+ Neu" in den Batch-Aktionen und wählen Sie "Verknüpfung“.
  <img src={require("./img/link/new-button.png").default} width="1920" height="1004" loading="lazy" decoding="async"/>

  <img src={require("./img/link/shortcut-button.png").default} width="400" height="644" loading="lazy" decoding="async"/>

- Link oder Datei einfügen
  - Geben Sie in dem sich öffnenden Fenster den Link oder den Namen der Datei ein, die Sie verlinken möchten.
  - Alternativ können Sie die gewünschte Datei auch aus der Liste auswählen, nachdem Sie die ersten Buchstaben eingegeben haben.
    <img src={require("./img/link/pop-up-window.png").default} width="500" height="209" loading="lazy" decoding="async"/>

- Verknüpfung benennen
  - Geben Sie einen Namen für die Verknüpfung ein.
    <img src={require("./img/link/url-and-title.png").default} width="500" height="312" loading="lazy" decoding="async"/>

- Verknüpfung erstellen
  - Klicken Sie auf "Erstellen“, um die Verknüpfung zu speichern.
    <img src={require("./img/link/create-button.png").default} width="400" height="249" loading="lazy" decoding="async"/>

## Verknüpfung nutzen

- Klicken Sie auf die Verknüpfung, um die verlinkte Webseite oder Datei in einem neuen Browser-Tab zu öffnen,
  <img src={require("./img/link/shortcut.png").default} width="1920" height="1093" loading="lazy" decoding="async"/>
- oder mit einem „Rechtsklick“ und „Öffnen “.
  <img src={require("./img/link/shortcut-right-click.png").default} width="1920" height="1142" loading="lazy" decoding="async"/>

  öffnet sich die verlinkte Webseite oder Datei in einem neuen Browser-Tab.
