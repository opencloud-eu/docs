# Notifications and Logging

Configure how OpenCloud informs users and records what happens on the server.  
This section shows how to send notifications by email and how to set log levels to monitor your instance and diagnose problems.

## In this section

- [Mail notifications](./mail-notifications.md)  
  Configure the SMTP settings so that OpenCloud can send notification emails to users.

- [Logging](./logging.md)  
  Set the global or service-specific log level and find the log output of your deployment.
