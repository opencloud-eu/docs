# Integrations

Extend OpenCloud with external services.  
This section explains how to add calendar and contacts, automate workflows, and use an alternative thumbnail generator for additional image formats.

## In this section

- [Calendar and contacts with Radicale](./radicale-integration.md)  
  Provide a CalDAV and CardDAV server for calendars and contacts through OpenCloud.

- [Automation with n8n](./n8n.md)  
  Use the OpenCloud node for n8n to automate workflows with files, folders, Spaces, and users.

- [imagor as thumbnail generator](./thumbnailer.md)  
  Replace the built-in thumbnail generator with imagor to create previews for HEIC, HEIF, and AVIF images.
