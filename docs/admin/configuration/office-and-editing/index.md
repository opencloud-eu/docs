# Office and Editing

Let users create and edit documents directly in OpenCloud.  
This section covers the integration of office suites and real-time collaborative editing for text files in the built-in editor.

## In this section

- [Collabora](./collabora/index.md)  
  Integrate Collabora Online, install additional fonts, and enable Microsoft Office formats in the New menu.

- [Euro-Office](./euro-office.md)  
  Set up Euro-Office with OpenCloud. This guide is community documentation and not officially supported.

- [Collaborative editing with the Yjs server](./collaborative-editing.md)  
  Allow several users to edit the same text file at the same time in the built-in editor.
