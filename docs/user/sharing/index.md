# Share files and folders

This section explains how sharing works in OpenCloud. It covers internal sharing with members and groups, public links for external access, File Drop links for receiving uploads, and sharing with users on other OpenCloud instances through OpenCloud Mesh.

## In this section

- [Internal sharing](./internal.md)  
  Share files and folders with members or groups within your organization.

- [External sharing](./external.md)  
  Create public links and manage options such as permissions, passwords, and expiry dates.

- [File Drop](./file-drop.md)  
  Allow external users to upload files without giving them access to existing content.

- [OpenCloud Mesh](./opencloud-mesh.md) - Connect with users on another OpenCloud instance and share files or folders with them.
