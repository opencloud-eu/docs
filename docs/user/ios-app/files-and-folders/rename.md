# Rename Files and Folders

To rename a file or folder in the OpenCloud iOS App:

- Tap the three dots (⋯) next to the item you want to rename

  <img src={require("../img/files-and-folders/rename/three-dots.png").default} alt="Click on the three dots menu" width="184" height="400" loading="lazy" decoding="async"/>

- Select "Rename" from the menu

  <img src={require("../img/files-and-folders/rename/select-rename.png").default} alt="Select rename" width="184" height="400" loading="lazy" decoding="async"/>

- Enter the new name for the file or folder

  <img src={require("../img/files-and-folders/rename/enter-rename.png").default} alt="Enter the new name" width="184" height="400" loading="lazy" decoding="async"/>

- Tap "Done" to apply the changes

  <img src={require("../img/files-and-folders/rename/tap-done.png").default} alt="Tap done" width="184" height="400" loading="lazy" decoding="async"/>
  <img src={require("../img/files-and-folders/rename/new-name-applied.png").default} alt="New applied name" width="184" height="400" loading="lazy" decoding="async"/>

The new name will be saved immediately.
