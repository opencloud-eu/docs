# Make Files Available Offline

You can make files available offline so they are accessible without an internet connection.

- Tap the three dots (⋯) next to the file

  <img src={require("../img/files-and-folders/make-available-offline/three-dots.png").default} alt="Make available offline" width="184" height="400" loading="lazy" decoding="async"/>

- Select “Make available offline”

  <img src={require("../img/files-and-folders/make-available-offline/make-available-offline.png").default} alt="Make available offline" width="184" height="400" loading="lazy" decoding="async"/>
  The file will be downloaded and stored locally on your device.

- Offline files are marked with a cloud icon with a checkmark.

  <img src={require("../img/files-and-folders/make-available-offline/marked-offline.png").default} alt="Make available offline" width="184" height="400" loading="lazy" decoding="async"/>

## Remove Offline Availability

To free up space:

- Tap the three dots (⋯) again on an offline file
- Select “Remove offline access”

These features ensure you’re always prepared — even when you’re offline!
