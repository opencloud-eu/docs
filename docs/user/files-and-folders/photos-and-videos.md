# Photos and Videos

OpenCloud can preview photos, Motion Photos, Live Photos, and videos directly in the web interface. You can browse media from the current folder without downloading each file first.

## Photo preview

Open a photo to display it in the preview viewer. The photo roll shows the other previewable media files in the folder. Select a thumbnail or use “Show previous media file in folder” and “Show next media file in folder” to move between files.

Use the viewer controls to:

- Enlarge or shrink the image. You can also hold `Ctrl`, or `⌘` on macOS, while using the mouse wheel.
- Rotate the image 90 degrees to the left or right.
- Select “Reset” to restore the original zoom and rotation.
- Show or hide the photo roll.
- Enter or exit full screen mode.

## Supported image formats

The preview viewer supports HEIC, HEIF, AVIF, and SVG files in addition to common image formats.

- HEIC, HEIF, and AVIF previews use a thumbnail generated by the server. If a preview cannot be generated, OpenCloud offers the file for download.
- SVG files can be opened in the preview viewer, but they are not included in the photo roll. Some unusual SVG files, such as files with embedded bitmap images, may not render.
- In end-to-end encrypted folders, the browser decodes images instead of the server. HEIC preview support therefore depends on the browser and is available in Safari. If the browser cannot decode the image, the viewer displays a message.

:::note
HEIC, HEIF, and AVIF previews depend on server-side thumbnail generation and the server configuration.
:::

## Motion Photos and Live Photos

OpenCloud supports Live Photos created with Apple devices and Motion Photos created with Android devices.

- A play icon identifies a Motion Photo or Live Photo in table and tile views.
- In tile view, hover over the photo to play it in a loop. Use the play icon to start or pause playback.
- When you open the photo in the preview viewer, it plays once automatically and then displays the still image.
- Select “Play Live Photo” or “Play Motion Photo” in the viewer to replay it. The control changes to “Pause Live Photo” or “Pause Motion Photo” during playback.

## Video playback

Videos open in the preview viewer and use the browser's video controls. You can play or pause the video, move through the timeline, adjust the volume, and enter full screen mode. The available controls and their appearance can vary by browser.

The toolbar below the viewer groups related actions: navigation between media files, view controls, and file actions such as adding a favorite or deleting the file when available.

## Notes

- The experience depends on the file type and browser capabilities.
- Very large media files may still take a moment to load.
- This feature is meant for quick viewing, not for advanced media editing.
