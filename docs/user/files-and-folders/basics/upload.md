# Upload Files and Folders

You can upload files and folders from your device to OpenCloud.

- Open the “+ New” menu in the left sidebar.

  <img src={require("./img/upload/upload-button.png").default} alt="Upload button" width="1920" height="520" loading="lazy" decoding="async"/>

- Select whether you want to upload files or folders.

  <img src={require("./img/upload/upload-options.png").default} alt="Select file or folder" width="400" height="84" style={{ display: "block", marginTop: "1rem", marginBottom: "1rem" }} loading="lazy" decoding="async"/>

- Select files/folders:
  - In the window that opens, select the desired files or folders.
  - Several files or folders can be selected at the same time.
- Confirm upload:
  - Click on “Open” to start the upload.

    <img src={require("./img/upload/upload-window.png").default} alt="Confirm upload" width="500" height="431" loading="lazy" decoding="async"/>

  - Once completed, a message will appear in the bottom right-hand corner.

- Alternatively:
  - Drag and drop the files or folders directly from your Explorer window into the browser to upload them.
