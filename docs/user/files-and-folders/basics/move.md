# Move Files and Folders

You can move files and folders to another location in OpenCloud.

1. Select the file or folder you want to move.

   <img src={require("./img/move/mark-folder.png").default} alt="Selected folder to move" width="1920" height="1080" loading="lazy" decoding="async"/>

2. Choose “Move to” in one of the following ways:
   - Open the context menu by right-clicking the selected item or selecting its three-dot menu, then choose “Move to”.

     <img src={require("./img/move/right-click-move-to-option.png").default} alt="Move to option in the context menu" width="400" height="703" loading="lazy" decoding="async"/>

   - Choose “Move to” from the action bar.

     <img src={require("./img/move/actionbar-move-to-option.png").default} alt="Move to option in the action bar" width="1920" height="1080" loading="lazy" decoding="async"/>

3. In the dialog, select the destination folder and choose “Move here”.

   <img src={require("./img/move/move-dialog.png").default} alt="Dialog for selecting the destination folder" width="1920" height="1080" loading="lazy" decoding="async"/>

4. The moved item appears in the destination folder and no longer exists in its original location.

   <img src={require("./img/move/moved-file.png").default} alt="Moved item in the destination folder" width="1920" height="1080" loading="lazy" decoding="async"/>
