# Rename Files and Folders

You can rename files and folders at any time in the web interface.

- Open the context menu by either:
  - right-clicking on the file or folder
  - or clicking on the three dots on the right in the corresponding line.
- Select the “Rename” option.
  <img src={require("./img/rename/rename-option.png").default} alt="Select rename" width="400" height="618" loading="lazy" decoding="async"/>
- Enter the new name for the file or folder in the window that appears.
  Confirm by clicking on “Rename”.

  <img src={require("./img/rename/rename-popup.png").default} alt="Enter new name" width="400" height="183" loading="lazy" decoding="async"/>

Done! - the new name is applied!
