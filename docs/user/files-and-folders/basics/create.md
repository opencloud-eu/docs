# Create Files and Folders

You can easily create new folders as well as text, table, and presentation files in the web interface.

- Open the “+ New” menu in the left sidebar.
  <img src={require("./img/create/new-button.png").default} alt="New button" width="1920" height="900" loading="lazy" decoding="async"/>
- Select either “Folder” or the desired "file type" that you want to create.
  <img src={require("./img/create/create-options.png").default} alt="Select file type or folder" width="400" height="558" loading="lazy" decoding="async"/>
- Enter a name for the file or folder in the window that appears.
- Click on “Create”.

  <img src={require("./img/create/create-button.png").default} alt="Click create" width="400" height="201" loading="lazy" decoding="async"/>

Done! The file or folder is created. If it is a file, it is automatically opened in edit mode.
