# Encryption

Protect particularly sensitive content with end-to-end encryption.  
Files and file names in an encrypted folder are encrypted in the browser before upload, so only people who have access to the folder and know its password can read them. This section explains how to create and use encrypted folders and how to access them with rclone.

## In this section

- [End-to-end encrypted folders](./e2ee-folders.md)  
  Create password-protected folders whose content is encrypted before upload.

- [Access encrypted folders with rclone](./e2ee-folders-rclone.md)  
  Mount an encrypted folder on Linux, macOS, or Windows with rclone.
