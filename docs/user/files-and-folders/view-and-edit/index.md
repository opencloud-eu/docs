# View and Edit

Open and work with your content directly in the browser, without downloading it first.  
This section covers previews of photos and videos, the built-in Markdown editor, and README files that describe the content of a folder.

## In this section

- [Photos and videos](./photos-and-videos.md)  
  Preview photos, browse them in a photo roll, and play videos in the web interface.

- [Edit Markdown files](./markdown-editor.md)  
  Edit `README.md` and other Markdown files directly in OpenCloud with formatting suggestions.

- [README files in folders](./readme-files.md)  
  Add a `README.md` file to a folder so OpenCloud displays it above the file list.
