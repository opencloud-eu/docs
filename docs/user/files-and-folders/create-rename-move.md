# Create - Rename - Move

You can easily create new text, table and presentation files in the web interface. You can also rename files and folders or move them to another location.

## Create files and folders

- Open the “+ New” menu in the left sidebar.
  <img src={require("./img/create-rename-move/new-button.png").default} alt="New button" width="1920"/>
- Select either “Folder” or the desired "file type" that you want to create.
  <img src={require("./img/create-rename-move/create-options.png").default} alt="Select file type or folder" width="400"/>
- Enter a name for the file or folder in the window that appears.
- Click on “Create”.

  <img src={require("./img/create-rename-move/create-button.png").default} alt="Click create" width="400"/>

Done! The file or folder is created. If it is a file, it is automatically opened in edit mode.

## Rename files or folders

- Open the context menu by either:
  - right-clicking on the file or folder
  - or clicking on the three dots on the right in the corresponding line.
- Select the “Rename” option.
  <img src={require("./img/create-rename-move/rename-option.png").default} alt="Select rename" width="400"/>
- Enter the new name for the file or folder in the window that appears.
  Confirm by clicking on “Rename”.

  <img src={require("./img/create-rename-move/rename-popup.png").default} alt="Enter new name" width="400"/>

Done! - the new name is applied!

## Move files or folders

1. Select the file or folder you want to move.

   <img src={require("./img/create-rename-move/mark-folder.png").default} alt="Selected folder to move" width="1920"/>

2. Choose “Move to” in one of the following ways:
   - Open the context menu by right-clicking the selected item or selecting its three-dot menu, then choose “Move to”.

     <img src={require("./img/create-rename-move/right-click-move-to-option.png").default} alt="Move to option in the context menu" width="400"/>

   - Choose “Move to” from the action bar.

     <img src={require("./img/create-rename-move/actionbar-move-to-option.png").default} alt="Move to option in the action bar" width="1920"/>

3. In the dialog, select the destination folder and choose “Move here”.

   <img src={require("./img/create-rename-move/move-dialog.png").default} alt="Dialog for selecting the destination folder" width="1920"/>

4. The moved item appears in the destination folder and no longer exists in its original location.

   <img src={require("./img/create-rename-move/moved-file.png").default} alt="Moved item in the destination folder" width="1920"/>
