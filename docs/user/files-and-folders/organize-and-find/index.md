# Organize and Find

Keep track of your content, even when there is a lot of it.  
This section explains how to find files quickly, mark important items, group them with tags, and create shortcuts to files or web links.

## In this section

- [Search for files and content](./search.md)  
  Find files by name, by tag, or by searching within their content.

- [Favorites](./favorites.md)  
  Mark frequently used files and folders and open them from the Favorites page.

- [Add and remove tags](./tags.md)  
  Label files and folders with tags to group related content and find it again.

- [Create shortcuts to files or web links](./shortcut.md)  
  Add shortcuts to frequently used files or external websites for quick access.
