# Web Interface

Adjust what users see in the OpenCloud web interface.  
This section shows how to set the default language, provide additional web apps, display announcements to all users, and control the frontend update check.

## In this section

- [Default language](./default-language.md)  
  Set the language that OpenCloud uses when a user has not selected a language of their own.

- [Web applications](./web-applications.md)  
  Install additional web applications for your users from the App Store.

- [Announcement banner](./announcement-banner.md)  
  Display a banner at the top of the web interface, for example to announce maintenance windows.

- [Frontend update check](./frontend-update-check.md)  
  Disable the check in the web interface that verifies whether you are running the latest OpenCloud version.
