# Delete Files and Folders

You can delete files and folders that you no longer need. Deleted items are moved to the “Deleted files” area first and can be restored from there.

- Select the file(s) or folder(s) you wish to delete.

  <img src={require("./img/delete/mark-folder.png").default} alt="Mark folder or file" width="1920" height="1080" loading="lazy" decoding="async"/>

- Open the context menu and select "Delete".

  <img src={require("./img/delete/delete-options.png").default} alt="Click delete" width="1920" height="1080" loading="lazy" decoding="async"/>

:::info
Alternatively, you can also click on “Delete” in the action bar.
:::

- The files or folders are moved to the “Deleted files” area. They can be restored from there if necessary.

  <img src={require("./img/delete/folder-in-deleted-files.png").default} alt="Removed files and folders in deleted files" width="1920" height="1080" loading="lazy" decoding="async"/>

To get deleted items back, see [Restore files and folders](./restore.md).
