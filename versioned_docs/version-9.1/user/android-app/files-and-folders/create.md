# Create Files and Folders

With the OpenCloud Android App, you can create new folders and documents directly on your phone or tablet.

Tap the “+” button in the bottom right corner.

<img src={require("../img/files-and-folders/create-android/create-new.png").default} alt="Create new" width="180" height="400" loading="lazy" decoding="async"/>

Choose what you want to create from the menu:

## Create a Folder

- Tap "New folder"
- Enter a name for your folder
- Tap "OK"

<img src={require("../img/files-and-folders/create-android/create-folder.png").default} alt="Create folder" width="180" height="400" loading="lazy" decoding="async"/>

## Create a Document (Requires Collabora)

If Collabora Online is enabled in your OpenCloud instance:

- Tap "New document"
- Choose the document type (text, spreadsheet, presentation)
- Enter a filename and confirm

<img src={require("../img/files-and-folders/create-android/choose-file-type.png").default} alt="Choose file type" width="180" height="400" loading="lazy" decoding="async"/>

The document will open in a built-in browser window using **Collabora** for editing.

<img src={require("../img/files-and-folders/create-android/open-collabora.png").default} alt="Open Collabora" width="180" height="400" loading="lazy" decoding="async"/>
