# Move or Copy Files and Folders

To move a file or folder in the OpenCloud Android App:

- Tap the "three dots (...)" next to the file or folder you want to move

<img src={require("../img/files-and-folders/move-android/three-dots-move.png").default} alt="Select the three dot menu" width="180" height="400" loading="lazy" decoding="async"/>

- Select "Move" or "Copy" from the menu

<img src={require("../img/files-and-folders/move-android/select-move-or-copy.png").default} alt="Select move or copy" width="180" height="400" loading="lazy" decoding="async"/>

Navigate to the destination folder
Tap "Move here" or "Copy here"

<img src={require("../img/files-and-folders/move-android/select-paste.png").default} alt="Select paste" width="180" height="400" loading="lazy" decoding="async"/>
<img src={require("../img/files-and-folders/move-android/file-moved.png").default} alt="File is moved" width="180" height="400" loading="lazy" decoding="async"/>

The file or folder will now appear in the new location.
