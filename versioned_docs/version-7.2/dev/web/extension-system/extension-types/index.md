title: 'Extension Types'

This section is a guide about the different predefined extension types of OpenCloud Web. Please refer to the respective
subpages to learn more about the individual extension types.

## In this section

- [Action extensions](./action-extensions.md) - Register actions that are rendered across the UI
- [Application menu item extensions](./app-menu-item-extensions.md) - Add links to the application switcher
- [Custom component extensions](./custom-component-extensions.md) - Render custom components at defined extension points
- [Folder view extensions](./folder-view-extensions.md) - Provide new views for folders, files, and spaces
- [Left sidebar menu item extensions](./left-sidebar-menu-item-extensions.md) - Add items to the left sidebar
- [Right sidebar panel extensions](./right-sidebar-panel-extensions.md) - Add panels to the right sidebar
- [Search extensions](./search-extensions.md) - Add search providers to the top bar search
- [Floating Action Button extensions](./floating-action-button-extensions.md) - Register actions for the left sidebar or as a floating button on mobile
